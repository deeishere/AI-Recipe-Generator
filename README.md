# AI Recipe Generator

A bilingual Streamlit app that creates recipes in English or Arabic from ingredients you provide.

## Run locally

```bash
pip install -r requirements.txt
export OPENROUTER_API_KEY="your-openrouter-api-key"
streamlit run recipe.py
```

The API key is read from the `OPENROUTER_API_KEY` environment variable. Do not commit it to the repository.
